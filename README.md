# Skyline Technology Inc. 企業サイト

Skyline Technology Inc. のコーポレートサイトです。HTML ファイル 1 つで構成されたワンページサイトで、ビルドやサーバーの準備は不要です。

## 概要

クラウド、システム開発、データ活用、セキュリティなどのサービスを紹介する企業サイトです。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと、相談・サービス紹介へのボタン |
| 実績 | 実績の数字（スクロール時にカウントアップ） |
| サービス | 6 つの提供サービスの紹介 |
| 会社紹介 | 会社の説明と強み |
| 進め方 | ヒアリング → 設計 → 開発 → 運用・改善 の 4 ステップ |
| 対応業界 | 対応している業界の一覧 |
| お問い合わせ | 連絡先とお問い合わせフォーム |

### 主な機能

- スマートフォン・タブレット・パソコンに対応したレスポンシブデザイン
- ライト／ダークモードの切り替え（端末の設定にも自動で対応）
- スクロールに合わせた表示アニメーション
- お問い合わせフォームの入力チェック

### ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS・JavaScript をすべて含む）
└── README.md    # このファイル
```

## ブラウザで index.html を開く手順

### 方法 1：ダブルクリックで開く（いちばん簡単）

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

ブラウザを選びたい場合は、`index.html` を右クリックし、「プログラムから開く」から使いたいブラウザを選んでください。

### 方法 2：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法 3：コマンドで開く

PowerShell の場合は、`company-site` フォルダで次のコマンドを実行します。

```powershell
Start-Process index.html
```

Git Bash の場合は、次のコマンドを実行します。

```bash
start index.html
```

> **補足：** フォント（Noto Sans JP、Inter）は Google Fonts から読み込んでいます。インターネットに接続していない場合は、パソコンに入っている標準のフォントで表示されます。

## 公開前の注意事項

- **仮の情報：** 電話番号、住所、メールアドレスは仮の値です。`index.html` 内の該当箇所を実際の情報に書き換えてください。
- **実績の数字：** 実績の数字（15年+、300件+、99.9%）も仮の値です。実際の数字に変更するか、削除してください。
- **お問い合わせフォーム：** 現在はメッセージを送信しません。実際に受け取るには、Formspree や Netlify Forms などのフォームサービス、または自社サーバーとの連携が必要です。
